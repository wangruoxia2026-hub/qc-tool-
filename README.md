## Web 端使用方法

默认入口为浏览器版（`python -m qc_tool`，自动开浏览器；`--no-browser` 关闭）：
检测指标按名称聚合为卡片，卡片内列出 L / H 两个水平子行。

- **点 L / H 子行**：质控图只显示该水平一条曲线（单图，样式同 §E.1）；
  中间区头部同步只显示该水平的靶值 / SD。
- **点卡片空白处 / 指标名**：质控图显示 L+H 双轴图（左轴 L、右轴 H，控制限
  像素级重合），头部显示双水平信息（2026-10-14 用户需求第 4 条）。
- 仅一个水平存在时，两种点击均为该水平的单图。

## 功能 E 使用方法

启动主程序后，菜单 `系统 → 质控图…` 打开质控图对话框。
顶部下拉按 4 维（检测指标 + 水平 + 批号 + 月份）过滤，切换即重绘。

- **水平下拉默认"L+H 双轴"**（2026-10-12 用户第二次补充，取代并排双图）：
  同指标同批号 L/H 两水平都存在时，画布显示一图双 y 轴（左轴 L 测定值、
  右轴 H 测定值，两侧 7 条控制限像素级重合）；缺一水平自动回退单图。
  横轴同日 L/H 逐点配对同 x：该日 L、H 各自按（seq, 录入顺序）排序后，
  第 i 个 L 点与第 i 个 H 点共用第 i 个横位，日期刻度居该日组中点
  （2026-10-13 用户第四次调整）。
  点样式：L 在控绿实心圆 / 警告黄实心圆 / 失控红实心圆，
  H 在控蓝实心三角 / 警告黄实心三角 / 失控红实心三角。
  也可选单一 L / H 查看单图（样式保持 §E.1：在控黑圆点/警告黄三角/失控红圆）。
- `<` / `>` 按钮：上 / 下月翻页。
- `图表配置`：6 个字段（项目名称 / 质控品批号 / 靶值 / SD / 仪器操作 / 前处理）可独立显隐；`时间范围` 始终保留作为兜底（2026-10-13 用户需求，原 12 字段中检测指标 / 简称 / 单位 / 厂家 / 水平不再上标题）。
- 标题格式（2026-10-13 用户需求）：首行 `项目名称+质控图`（字号为其余行 2 倍），第二行 `质控品批号：…   靶值（L）=…   SD（L）=…   靶值（H）=…   SD（H）=…` 一行平铺（单图为批号+该水平靶值/SD），随后 `仪器操作：…`、`前处理：…`、`时间范围：YYYY-MM-DD~YYYY-MM-DD` 各自一行。双轴图中仪器操作 / 前处理 L/H 相同时显示一行、不同时分（L）（H）两行（批号不同时在平铺行内分（L）（H）两段）；可选字段为空时跳过该行。
- `导出图片`：PNG / JPG 导出当前图（DPI 默认 300，元信息显隐由"图表配置"决定；双轴模式下导出整张双轴图）。
- **点击图上数据点**：右侧面板显示该点排查信息；**失控点**在排查信息下方显示
  「结果发放建议」——中间点提示前后相邻序号区间、当日最后点提示前点至该点区间、
  当日首点提示"当日开始至该点"区间内样本结果不允许发放；**连续失控点自动合并区间**
  （如 3、4 号失控 → "当日2-5质控点区间内结果不允许发放"）（2026-10-14 用户需求；
  区间只在同日闭合，详见 spec §F.3）。

## 功能 G 使用方法

启动主程序后，菜单 `报表` 提供两个入口：

- **生成月报…**：选项目 + 月份 → 弹出"选择导出指标"对话框（每个「检测指标 +
  水平」为一个可勾选指标）→ 至少勾选 1 个 → 保存为多 sheet `.xlsx`。
  每个勾选指标生成 4 个 sheet：
    - `本月原始` —— 全部测定值 + 状态
    - `累计统计` —— 检测指标建立日 ~ 上一自然月最后一天
    - `去失控累计` —— 排除"失控"与"作废"后重算
    - `质控图` —— 嵌入质控图：L+H 成对时为一图双 y 轴（左轴 L、右轴 H，控制限
      重合），单水平为单图（2026-10-12 用户第二次补充；openpyxl 嵌图依赖 pillow）
- **失控记录导出…**：选项目 + 时间段（本月 / 上月 / 今日 快捷按钮）→
  选 Excel 或 PDF → 保存。xlsx 全字段（含触发日期 / 规则 / 处理过程 /
  已检查项 / 处理人 / 审核人 / 审核备注 / 样本批次 / 样本编号 / 误差类型等）；
  PDF 矢量（DPI 关闭流压缩；字号 ≥ 10pt）。

边界提示：月内无数据 → "无数据"；未勾选任何指标 → "请至少勾选一个指标"；
时间段无失控 → "该时间段无失控记录"。
